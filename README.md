# Tetron

Tetron is a simple Tetris-inspired game built with JavaScript. It recreates the classic block-stacking experience, challenging players to arrange falling pieces, complete horizontal lines, and keep the board from filling up.

Developed as a project to practice JavaScript and game development fundamentals.

## Features

- Classic Tetris-inspired gameplay
- Falling tetrominoes
- Line-clearing mechanics
- Simple and lightweight implementation

## Technologies

- JavaScript
- HTML
- CSS
